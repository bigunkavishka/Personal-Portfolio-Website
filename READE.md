## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. View the website in your browser.

## Customization

- Update your personal information in `index.html`.
- Change the design in `style.css`.
- Add interactive features in `script.js`.
- Replace the profile photo inside the `assets` folder.
